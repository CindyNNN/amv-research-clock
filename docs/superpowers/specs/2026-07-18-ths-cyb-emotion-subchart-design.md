# 同花顺远航版创业板情绪副图设计

## 目标

在创业板指（399006）日线中增加一个 Python 副图，展示 2020 年至今的市场情绪历史、冰点阈值和策略买卖信号。副图与现有 QQ 邮件监控共用同一套数据和规则，避免两套实现产生口径漂移。

## 副图内容

- 市场情绪：上涨家数 /（上涨家数 + 平盘家数 + 下跌家数）× 100。
- 冰点线：固定为 15。
- 买入标记：空仓时，情绪 < 15 且 KDJ 的 J < 30。
- 卖出标记：持仓后，`KDJ 死叉且收盘价 < MA20`，或者收盘价相对持仓期间最高收盘价回撤达到 8%。
- 持仓状态线：空仓为 0，持仓为 100，使用较淡颜色显示。
- 最新一根有效数据上显示“持仓/空仓”和数据日期。

## 数据流

每日监控程序下载并校验创业板指日 K 和同花顺涨跌分布数据，然后从 2020 年开始回放策略。程序以原子替换方式生成：

`data/monitor/ths_cyb_emotion_subchart.csv`

文件字段固定为：

`date,close,emotion,j,signal,holding`

其中 `signal` 只允许 `BUY`、`SELL`、`HOLD`、`FLAT`。

副图脚本只读取这个文件，不自行联网，也不接触邮箱授权码。

## K 线对齐

远航版现有示例没有公开可用的交易日期字段，因此第一版不依赖日期 API。脚本使用创业板指收盘价序列自动对齐：

1. 从外部文件末尾向前寻找与当前图表最近收盘价相匹配的位置。
2. 用连续最多 5 根收盘价验证候选位置，允许每点 0.05 点误差。
3. 若当天尚未收盘、外部文件尚无当天数据，允许图表最后一根临时 K 线留空，历史部分仍按前一交易日对齐。
4. 若无法找到至少 3 根连续匹配，副图不画情绪和信号，只显示“数据未对齐”，避免静默错位。

## 运行与安装

- 每次运行 `run_cyb_signal_monitor.bat` 都更新副图数据文件；邮件发送失败不回滚已经校验成功的行情文件。
- 提供可直接粘贴到远航版 Python 指标编辑器的脚本：
  `ths_indicators/cyb_emotion_subchart.py`
- 脚本只使用远航版已验证的 `get`、`save`、`draw.curve`、`text` 和 Python 标准文件读取能力。
- 使用前必须打开创业板指 399006 的日线；其他证券或周期因无法通过日期/证券代码 API 严格验证，副图将尽量通过收盘价匹配拒绝错误对齐。

## 风险和限制

- 2020—2021 年情绪来自历史缓存，2022 年以后来自同花顺涨跌分布接口；图中展示的是严格回测口径，不保证与同花顺界面包含停牌股后的显示值完全相同。
- 盘中最后一根 K 线不产生新信号；信号以完整日线收盘数据为准。
- 这是研究和提醒工具，不自动下单，也不构成投资建议。
