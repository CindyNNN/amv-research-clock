# 通达信创业板情绪副图设计

## 目标

为本机 `C:\Softwares\new_tdx\tdxw.exe` 增加创业板指 `399006.SZ` 日线情绪策略副图。副图与现有 QQ 邮件监控、历史回测共用相同的数据和状态机，不连接交易账户，不调用委托接口。

## 已确认的运行能力

- 本机安装包含 `PYPlugins\user\tqcenter.py`，并支持 Python 3.11。
- 通达信官方 TdxQuant 提供 `tq.send_bt_data()`，可以按证券代码和时间序列向客户端推送最多 16 个数值字段。
- 通达信公式系统提供 `SIGNALS_TQ(ID, TYPE)`，可以在技术指标公式中读取上述序列。
- 运行推送程序前必须打开并登录支持 TQ 的通达信客户端。

## 架构

保留现有数据下载、历史策略回放和 QQ 邮件模块。新增独立的通达信推送程序，从已经原子生成的：

`data/monitor/ths_cyb_emotion_subchart.csv`

读取严格按日期排序的历史数据，转成 `send_bt_data` 所需的 `time_list` 和 `data_list`，推送给 `399006.SZ`。

推送程序和邮件程序相互隔离：

- 邮件及历史 CSV 生成成功后才尝试通达信推送。
- 通达信未打开、未登录或 TQ 初始化失败时，推送程序返回非零退出码并显示可操作提示。
- 通达信推送失败不得撤销行情缓存、历史 CSV 或邮件状态，也不得造成重复邮件。

## 序列协议

每个交易日向通达信发送六个纯数字字符串：

| SIGNALS_TQ ID | 名称 | 数值 |
|---|---|---|
| 1 | 市场情绪 | `emotion`，范围 0—100 |
| 2 | 买入信号 | 当日 `signal == BUY` 时为 1，否则为 0 |
| 3 | 卖出信号 | 当日 `signal == SELL` 时为 1，否则为 0 |
| 4 | 持仓状态 | 持仓为 1，空仓为 0 |
| 5 | KDJ J值 | `j` |
| 6 | 创业板收盘价 | `close`，用于人工核验 |

`time_list` 使用 `YYYYMMDD`。`count` 必须等于实际历史行数，不截断到固定60日。推送前拒绝重复日期、非法信号、非有限数值以及非递增日期。

## 副图公式

提供可复制到“公式管理器 → 技术指标公式 → 其他类型”的公式：

- 黄色粗线：市场情绪。
- 白色线：固定冰点阈值15。
- 蓝色线：持仓状态乘100，100代表模型持仓、0代表模型空仓。
- 红色买入图标和文字：ID 2为1。
- 绿色卖出图标和文字：ID 3为1。
- J值和收盘价只作为不绘制的核验字段。

公式读取使用 `SIGNALS_TQ(ID, 2)`，没有对应数据的周期返回0，避免把旧信号平滑延续到下一周期。

## 每日运行

新增 `push_tdx_cyb_indicator.bat`，只负责把现有历史 CSV 推送给已经打开的通达信，便于单独重试。

现有 `run_cyb_signal_monitor.bat` 保存邮件监控命令的退出码；仅当退出码为0时调用上述推送脚本：

1. 更新创业板和市场情绪数据。
2. 发送每次运行状态邮件。
3. 原子更新副图历史 CSV。
4. 尝试连接通达信并推送全部历史序列。
5. 窗口显示邮件结果和通达信推送结果。

若行情处理、邮件发送或状态保存失败，批处理保留原始非零退出码并跳过通达信推送，避免把旧 CSV 当作当天结果再次推送。

通达信必须在运行前打开。推送完成后，用户进入 `399006` 日线并刷新副图。

## 测试与验收

- 单元测试验证 CSV 到六列 TQ 载荷的字段顺序、数值、日期和行数。
- 单元测试验证重复日期、非法信号和非有限数值被拒绝。
- 使用假的 `tq` 对象验证 `send_bt_data` 的证券代码为 `399006.SZ` 且 `count` 等于历史行数。
- 静态检查副图公式包含六个固定 ID、冰点线、买卖图标且不含任何交易函数。
- 全量测试通过后，在通达信已打开的情况下执行一次真实推送；成功标准是接口返回 `ErrorId == "0"`，并在 `399006` 日线显示完整历史情绪及买卖信号。

## 风险边界

- 工具仅发送研究数据，不导入或读取资金账号，不调用 `order_stock` 等交易接口。
- 2020—2021 年情绪来自项目历史缓存，2022 年以后来自同花顺全市场涨跌分布接口；这是严格回测口径，可能与其他软件包含停牌股后的界面值不同。
- 信号仅基于完整日线收盘数据；盘中不生成新的日线信号。
- 指数本身不可直接交易，副图和邮件均不构成投资建议。
