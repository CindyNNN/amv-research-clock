# Tech Board Trade Advice V1 Design

Created: 2026-06-17

## Goal

Build a read-only trading-advice layer for the existing technology-board dashboard. The feature should turn cached technology-board scores and market heat into practical, explainable trade suggestions without connecting to a broker or placing orders.

## Scope

The first version covers technology boards only. It uses the existing dashboard cache files generated by `refresh-dashboard`:

- `data/dashboard/latest/tech_board_scores.csv`
- `data/dashboard/latest/sentiment_history.csv`
- `data/dashboard/latest/data_status.json`

The output is a Markdown advice report and optional command-line printout.

## Non-Goals

- No automatic trading.
- No broker login, credentials, cookies, account access, or order placement.
- No individual stock entry/exit advice in this version.
- No position CSV analysis in this version.
- No promise of return or guarantee of signal accuracy.

## User-Facing Behavior

Add a CLI command:

```powershell
python -m ai_invest_advisor.cli trade-advice
```

Options:

- `--cache-dir`: defaults to `data/dashboard/latest`
- `--output-dir`: defaults to `reports/trade_advice`
- `--top`: defaults to `8`
- `--print`: prints the report after writing it

The generated report includes:

- Market stance: `积极进攻`, `均衡持有`, or `防守观望`
- Allocation guidance expressed as a range, not an instruction to trade
- Action buckets:
  - `可关注`: high score, positive or controlled flow, no major overheat flag
  - `等待回调`: strong score but short-term run-up or risk flags
  - `减仓/回避`: weak score, negative flow, or elevated risk
- Per-bucket reasons and risk notes
- Data timestamp/source status when available
- Disclaimer: `This is research support, not financial advice.`

## Recommendation Rules

Market stance:

- `积极进攻`: market heat is at least 70, average tech-board score is at least 65, and total net amount is positive.
- `防守观望`: market heat is below 45, average score is below 50, or total net amount is negative.
- `均衡持有`: all other cases.

Board buckets:

- `可关注`: score >= 70, net amount >= 0, `ret5` <= 12, and risk flags are empty or equivalent to no obvious abnormality.
- `等待回调`: score >= 60 but either `ret5` > 12 or risk flags are present.
- `减仓/回避`: everything else, sorted by lowest score first.

The feature must treat missing optional columns as neutral values and must fail clearly if required cache files are missing.

## Error Handling

- Missing `tech_board_scores.csv`: tell the user to run `refresh-dashboard` first.
- Missing `sentiment_history.csv`: use market heat `0` and mark the data quality warning.
- Empty score table: generate a report with warnings instead of crashing.
- Malformed numeric fields: coerce safely and include a data quality warning.

## Testing

Unit tests should cover:

- Strong market stance with focus candidates.
- Defensive market stance with avoid candidates.
- Overheated high-score board routed to wait-for-pullback.
- Missing sentiment file warning path.
- CLI parser accepts `trade-advice` and options.

## Acceptance Criteria

- `pytest -q` passes offline.
- `python -m ai_invest_advisor.cli trade-advice --cache-dir data/dashboard/latest --output-dir reports/trade_advice` writes a Markdown report when cache exists.
- Report contains market stance, allocation guidance, all three action buckets, risk notes, and the disclaimer.
- No code path can place orders or request brokerage credentials.
