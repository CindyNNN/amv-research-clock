# 创业板情绪策略卖出规则研究设计

日期：2026-07-18

## 目标

在不改变买入规则的前提下，寻找比固定持有9个交易日更好的卖出规则。主要优化目标为收益与回撤平衡：

- 计入单边0.1%交易成本后，累计收益高于当前基准101.57%；
- 全样本最大回撤不超过20%；
- 规则可由每日收盘数据计算，并可接入现有邮件监控和通达信指标；
- 结果不能只依赖单一年份或孤立的最优参数。

当前基准为：全市场情绪小于15且创业板指收盘不低于MA250，下一交易日开盘买入，持有9个交易日后收盘卖出。

## 数据与样本

- 创业板指：`data/backtests/cyb_emotion_kdj/cyb_399006_daily.csv`
- 全市场涨跌家数：`data/backtests/cyb_emotion_kdj/all_a_breadth_combined.csv`
- 样本区间：2020-01-02至2026-07-17
- 情绪口径：`上涨家数 / (上涨家数 + 下跌家数) * 100`
- 趋势过滤：信号日创业板指收盘价不低于MA250
- 一次只持有一笔；待买入和持仓期间忽略新冰点信号；卖出当天不安排新买入

MA250必须使用2019年开始的创业板指历史数据预热，不能从2020年才开始滚动计算。

## 成交假设

- 买入信号在交易日收盘后确认，下一交易日按开盘价买入。
- 固定期限卖出已提前确定，可按指定交易日收盘价卖出。
- 依赖收盘价、均线、KDJ或最高收盘回撤的条件型卖出，在当日收盘后确认，下一交易日按开盘价卖出。
- 基于日内最高价、最低价触发的止损或止盈不作为主结果，避免假设无法验证的日内成交顺序。
- 主结果使用单边0.1%成本；单边0.15%作为成本敏感性测试。
- 不考虑融资、冲击成本、税费差异和指数产品跟踪误差。

## 候选卖出规则

### 固定期限

- 买入后持有5至15个交易日，在到期日收盘卖出。

### 固定收益阈值

- 收盘亏损达到4%、6%或8%时触发卖出；
- 收盘盈利达到5%、8%、10%或12%时触发卖出；
- 阈值触发后下一交易日开盘卖出；
- 所有规则必须配合最长持有期，最长持有期从9、12、15日中选择。

### 最高收盘回撤

- 从持仓后的最高收盘价回撤4%、6%、8%或10%时触发卖出；
- 可设置盈利达到3%或5%后才启用移动止损；
- 触发后下一交易日开盘卖出；
- 配合最长持有9、12或15日。

### ATR波动止损

- 使用ATR14；
- 从持仓后的最高收盘价减去2、2.5或3倍ATR作为移动退出线；
- 触发后下一交易日开盘卖出；
- 配合最长持有9、12或15日。

### 趋势与动量退出

- 收盘跌破MA5、MA10或MA20；
- KDJ死叉；
- 为避免买入后立即被噪声洗出，设置最少持有2或3个交易日；
- 条件触发后下一交易日开盘卖出；
- 配合最长持有9、12或15日。

### 组合规则

只组合一个风险保护条件和一个最长持有期，避免参数爆炸。重点组合包括：

- 最高收盘回撤 + 最长持有期；
- KDJ死叉 + 最高收盘回撤 + 最长持有期；
- 跌破短期均线 + 最高收盘回撤 + 最长持有期；
- ATR移动止损 + 最长持有期。

不测试三个以上独立技术条件的复杂组合。

## 评价指标

每条规则至少报告：

- 完整交易数；
- 计费前、单边0.1%和单边0.15%成本下的累计收益；
- 年化收益；
- 最大回撤；
- Calmar比率；
- 胜率；
- 单笔平均和中位数收益；
- 最好、最差单笔收益；
- 平均持有交易日；
- 分年度复合收益和交易数。

## 稳健性筛选

规则按以下顺序筛选：

1. 主样本最大回撤不超过20%；
2. 单边0.1%成本下累计收益高于101.57%；
3. 单边0.15%成本下仍为正且没有明显崩塌；
4. 至少三个有交易的年份盈利；
5. 任一单一年份贡献不应解释绝大部分累计利润；
6. 相邻参数必须得到方向一致的结果；
7. 交易数过少的规则只列为探索结果，不作为推荐。

排名时，在满足上述条件的规则中优先选择累计收益最高者，并用Calmar比率、最大回撤和规则复杂度作为并列决胜标准。

## 验证方法

- 检查日期唯一性、情绪缺失、OHLC关系和MA250预热；
- 对每条规则验证交易不重叠、无未定义的未来成交价格；
- 用逐日净值和逐笔收益乘积独立核对累计收益；
- 检查条件信号日与实际成交日严格错开，避免收盘后信号按同一收盘价成交；
- 对最优候选做留一年检验：逐年剔除一个年份后重新比较规则排名；
- 检查最优参数附近的参数平台，而不是只报告单个尖峰。

## 研究依据

- Kaminski与Lo指出，在随机游走条件下简单止损会降低预期收益，止损只有在存在动量或状态持续性时才可能增加价值。因此止损不能先验视为收益增强工具：<https://papers.ssrn.com/sol3/Delivery.cfm/SSRN_ID968338_code665721.pdf?abstractid=968338>
- Glynn与Iglehart研究了移动止损距离对收益分布和持有期限的影响，为测试最高价回撤退出提供理论依据：<https://pubsonline.informs.org/doi/pdf/10.1287/mnsc.41.6.1096>
- Leung与Zhang研究了移动止损约束下的买卖时机，说明移动止损与止盈可联合考虑，但本研究限制组合复杂度以降低过拟合：<https://arxiv.org/abs/1701.03960>

## 交付结果

- 一张全部卖出规则的汇总表；
- 一张合格规则排行榜；
- 最优规则与当前固定9日基准的净值、回撤和年度表现对比；
- 参数稳定性结果；
- 推荐规则、备选规则及明确风险说明；
- 可复现的回测脚本和测试。

## 非目标

- 不连接券商、不自动下单；
- 不使用盘中不可验证的数据顺序；
- 不通过机器学习拟合小样本退出规则；
- 不把样本内最高收益直接描述为未来可实现收益。
