# 通达信纯公式全市场情绪副图设计

## 目标

在 `C:\Softwares\new_tdx\tdxw.exe` 中建立不依赖 Python、TdxQuant、外部 CSV 或每日推送的创业板情绪副图。副图直接使用通达信本地历史行情中的市场涨跌家数，计算情绪并标注买卖点。

## 数据能力与限制

通达信公式函数：

- `ADVANCE`：返回指数对应市场的历史逐周期上涨家数。
- `DECLINE`：返回指数对应市场的历史逐周期下跌家数。
- `TOTALHQINFO(1/2)`：返回沪深京全市场当前上涨/下跌家数，但属于当前市场表现，不能用于历史逐日曲线。
- `CALCSTOCKINDEX`：在当前图表中引用指定证券的指定指标输出；被引用指数的对应周期数据必须已经下载到本地。

因此，历史纯公式版采用：

- `SH000001`：上海市场历史涨跌家数。
- `SZ399001`：深圳市场历史涨跌家数。
- `BJ899050`：北证50历史涨跌家数，作为北京市场近似。

纯公式无法取得每日全市场平盘家数，情绪口径固定为：

`情绪 = 上涨家数 / (上涨家数 + 下跌家数) × 100`

该口径与 Python 严谨回测使用的“上涨 /（上涨 + 平盘 + 下跌）”不完全相同；冰点阈值仍使用15，但历史信号和回测结果可能存在少量差异。

## 公式结构

### 辅助指标 `QXBASE`

类型：技术指标公式，画线方法选择副图。

固定输出：

1. `上涨:ADVANCE;`
2. `下跌:DECLINE;`

此指标只为 `CALCSTOCKINDEX` 提供两个历史输出，不作为用户日常观察的副图。

### 可视副图 `CYBQX`

类型：技术指标公式，画线方法选择副图。

通过 `CALCSTOCKINDEX` 分别读取三个指数的 `QXBASE` 第1、2输出，并合计：

- `UPN = 上海上涨 + 深圳上涨 + 北证50上涨`
- `DNN = 上海下跌 + 深圳下跌 + 北证50下跌`

当 `UPN + DNN > 0` 时计算情绪，否则返回 `DRAWNULL`，避免把数据缺失误画成0。

显示内容：

- 黄色粗线：情绪。
- 白色虚线：冰点15。
- 红色文字：当日上涨家数。
- 绿色文字：当日下跌家数。
- 红色“买”和图标：经过信号过滤的买入点。
- 绿色“卖”和图标：经过信号过滤的卖出点。
- 最新一根K线左上角显示当前情绪、上涨家数和下跌家数。

## KDJ与信号

KDJ使用通达信标准口径：

```text
RSV=(C-LLV(L,9))/(HHV(H,9)-LLV(L,9))*100
K=SMA(RSV,3,1)
D=SMA(K,3,1)
J=3*K-2*D
```

原始买入条件：

`情绪 < 15 AND J < 30`

原始卖出条件满足任一项：

1. `CROSS(D,K) AND C < MA(C,20)`
2. 收盘价低于“最近一次原始买入条件出现后最高收盘价”的92%。

使用 `TFILTER(原始买入, 原始卖出, 0)` 配对并过滤连续信号：

- 返回1为买入标记。
- 返回2为卖出标记。

## 8%回撤近似边界

通达信技术指标公式没有与 Python 状态机等价的可持久化持仓对象。回撤观察窗口从最近一次“原始买入条件”开始；如果持仓期间再次出现原始买入条件，窗口可能被重置。

因此：

- KDJ死叉且跌破MA20的卖出条件是确定的。
- 8%最高收盘回撤条件是视觉指标近似实现。
- `TFILTER`保证最终显示的买卖标记交替出现，但不能保证与 Python 严谨回测的每笔持仓完全一致。

## 安装与数据准备

1. 在通达信“系统 → 盘后数据下载”中下载 `SH000001`、`SZ399001`、`BJ899050` 的日线历史数据；至少覆盖希望查看的日期范围。
2. 先创建并保存 `QXBASE`。
3. 再创建并保存 `CYBQX`。
4. 打开创业板指 `399006` 日线，输入 `CYBQX`。
5. 若情绪显示空白，优先检查三个引用指数的本地日线是否完整，而不是把缺失值替换为0。

## 测试与验收

- 两个公式在本机公式编辑器中“测试公式”必须通过。
- 在 `SH000001` 和 `SZ399001` 图表上单独加载 `QXBASE`，上涨/下跌不得长期为0。
- 在 `399006` 日线加载 `CYBQX` 后，情绪应在0—100之间。
- 最新上涨和下跌家数应与通达信当日市场统计方向一致。
- 历史买卖标记必须交替出现，不允许连续多个买入或连续多个卖出。

## 风险边界

- 该指标只用于研究和提醒，不读取账户、不连接券商、不自动下单。
- 北证50只覆盖其成分股，不能完全代表北京市场全部股票。
- 平盘家数缺失导致本公式口径与 Python 回测口径不同。
- 指数本身不可直接交易，指标不构成投资建议。
